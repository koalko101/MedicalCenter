# DTO структуры ЭМК

Пакет содержит транспортные структуры ЭМК по разделам 5.1–5.18 постановления Минздрава № 75.

- `PatientEhrDto` — корневой объект карты.
- Данные пациента разделены на персональные и медицинские.
- Исследования, диагнозы, назначения, диспансеризация, инвалидность, регистры и согласия представлены отдельными DTO.
- `MedicalDocumentDto` содержит владельца и подписи исходного документа.
- `FileObjectReferenceDto` хранит ссылку и метаданные файла; бинарные данные размещаются отдельно.
